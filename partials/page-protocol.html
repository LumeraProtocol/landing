The gaps and the answers

What's missing today, and what closes it.

The gaps are architectural, not incremental, and they depend on each other. Identity without settlement is unenforceable. Settlement without identity is unaccountable. Open any row to see what breaks today and what replaces it.

Today

An agent’s identity is an API key belonging to someone else. Revocable, non-portable, carrying no independent reputation. It cannot accumulate a record, delegate authority, or be held accountable for anything.

On Lumera

LumeraID is the universal on-chain principal for users, agents, applications, data assets and providers. It is a container that accumulates claims over time.

03
Cascade · AetherDB
No durable memory
Durable Memory
Memory that survives switching providers.
+
Today

Agent state lives in provider-controlled databases. Switch providers, lose context. No memory the agent owns, no institutional knowledge that accumulates, no data sovereignty.

On Lumera

Cascade is content-addressed erasure-coded storage with BLAKE3 Merkle proofs. AetherDB is a leaderless quorum-replicated database for hot state. Large values overflow from one to the other transparently.

05
Councils · Packs
No verifiable workflows
Composable Intelligence
Workflows a second node re-runs to check.
+
Today

A multi-step job is a black box. You either trust the whole chain or none of it, and there is no universal way to check whether a workflow is reliable.

On Lumera

Packs are content-addressed workflow bundles registered on-chain. The hash guarantees the workflow that ran is the workflow that was registered. Councils govern who may invoke them.

Runner + Verifier. A runner executes; an independent verifier replays deterministic steps. Payment depends on lifecycle completion, never on subjective quality.

Lumera is where agent work becomes checkable: permanent memory, an identity the agent owns, a receipt for everything that ran, and settlement that clears in one place.
