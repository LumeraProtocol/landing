Agent memory

Give your agent a memory it can prove.

AI agents forget everything between sessions, and the memory they do have lives on someone else's server.

Lumera gives every agent permanent memory: stored once, retrievable from any framework or model, with cryptographic proof it is still there.

Read the docs → Open the app →
store · recall · prove 
import { memory } from '@lumera/sdk'

await memory.store(agent, 'customer prefers metric units')
const facts = await memory.recall(agent, 'units')
const proof = await memory.prove(facts.id)   // receipt, forever

Architecture

Written once. Verifiable forever.

Every session, settlement and computation leaves a permanent record, and the thing it points at is still there. Durable evidence, not notarization. Come back in a year and check exactly what happened, without permission and without taking anyone's word for it.
